Research data is most valuable when others can find it, understand it, trust it and reuse it, long after the
project that created it has ended. This module covers the principles of **curating and sharing geospatial
data**: describing data with metadata and documentation, preserving it for the long term, publishing it in
repositories with persistent identifiers and licenses, and protecting the people and places that location data
can reveal.

The module is **conceptual**: it has no programming or software exercises. Each episode includes examples and
challenges with solutions.

| Episode | What you will learn |
|---|---|
| Introduction to Data Curation | What curation is, the curation lifecycle, public access policies and the FAIR principles |
| Metadata | Kinds of metadata, essential geospatial elements, and standards such as ISO 19115, DataCite and DDI |
| Documentation | README files, codebooks, provenance, and citing data |
| Preservation | Durable formats, checksums, the OAIS model, trustworthy repositories and very large data |
| Sharing and Publishing Data | Choosing a repository, DOIs, licenses, access levels, and the FAIR and CARE principles |
| Ethics and Sensitive Location Data | Re-identification, aggregation and geomasking, sensitive places, consent and review |

- The **Data Management** module is helpful background, especially its episodes on file formats and organizing
