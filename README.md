# Curating and Sharing Geospatial Data

Source for the **Data Curation** module of
[Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/),
published at <https://spatialturn.github.io/datacurationmain/>.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/). It is a
theory-based module with no notebooks or data downloads.

| Episode file | Topic |
|---|---|
| `episodes/introduction.md` | Introduction to data curation, the curation lifecycle and FAIR |
| `episodes/metadata.md` | Metadata and metadata standards |
| `episodes/documentation.md` | README files, codebooks, provenance and data citation |
| `episodes/preservation.md` | Digital preservation, formats, checksums, repositories and large data |
| `episodes/sharing.md` | Repositories, DOIs, licenses, access levels, FAIR and CARE |
| `episodes/ethics.md` | Ethics and sensitive location data |

Figures named `cur_*.png` in `episodes/` were generated with Python (the geomasking figure uses simulated points
over U.S. Census Bureau boundaries) or drawn as diagrams. Each has a `-dark` copy for the site's dark mode.
